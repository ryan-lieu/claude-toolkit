Skills we wrote ourselves go here, one folder per skill (each with a SKILL.md), plus a `skills ... local path=skills/<name>`
line in manifest.txt. Skills that come from someone else's repo don't go here: list their repo in manifest.txt instead.

- `video-to-skill`: turn a reel, TikTok or YouTube tutorial into a working skill (needs the watch plugin; the
  Gemini second reading is optional and needs a free GEMINI_API_KEY in your environment, never in this repo).
